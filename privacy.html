Privacy

Last updated 26 October 2026

Sift is a free, static website. It has no accounts, no sign-up, no cookies, no analytics and no advertising trackers, and it does not sell personal data. The only thing it collects is described under Trace requests below.

What the pages do

  • The pages load Sift's own files (the page and its public data files, such as radar.json). They load no fonts, images or tracking scripts from other companies. The one outside script is Cloudflare Turnstile, loaded on the radar page only when you start a trace.
  • Searching the token list and checking a wallet happen in your browser. The wallet you paste is looked up in the public file radar-wallets.json and is never sent anywhere.
  • Nothing is saved in your browser between visits.

Hosting

The site is hosted on GitHub Pages. GitHub may log technical data such as visitors' IP addresses to run and secure the service; see the GitHub General Privacy Statement. Sift has no access to those logs.

Trace requests

Starting a trace sends the token address to a small relay hosted on Cloudflare, which starts the trace on GitHub. Before that, Cloudflare Turnstile checks that you are a person; the relay passes your IP address to Cloudflare for that check, handled under the Cloudflare privacy policy. To apply the daily limit, the relay writes a salted hash of your IP address (for IPv6, of its first half) next to the token address in the public run list of the trace job on GitHub. The IP address itself is never written, but the hash stays the same, so traces from the same connection can be seen to come from one requester. Sift keeps no other record; Cloudflare may log requests to run its service. A trace can also be requested by opening an issue on the public GitHub repository; issues are public, so only post the token address.

Links to other sites

Trade and chart links open other services (trading terminals, Solscan, GeckoTerminal), which have their own privacy policies. Where a referral code is used, the screener page says so.
