Privacy

Last updated 15 October 2026

Sift is a free, static website. It has no accounts, no sign-up, no cookies, no analytics and no advertising trackers, and it does not collect, store or sell personal data.

What the pages do

  • The pages load only Sift's own files (the page and its public data files, such as radar.json). They do not load fonts, scripts or images from other companies.
  • Searching the token list and checking a wallet happen in your browser. The wallet you paste is looked up in the public file radar-wallets.json and is never sent anywhere.
  • Nothing is saved in your browser between visits.

Hosting

The site is hosted on GitHub Pages. GitHub may log technical data such as visitors' IP addresses to run and secure the service; see the GitHub General Privacy Statement. Sift has no access to those logs.

Trace requests

A trace is requested by opening an issue on the public GitHub repository. Issues are public and are handled under GitHub's terms, so only post the token address.

Links to other sites

Trade and chart links open other services (trading terminals, Solscan, GeckoTerminal), which have their own privacy policies. Where a referral code is used, the screener page says so.

Contact

Questions about this page: open an issue on the GitHub repository.
